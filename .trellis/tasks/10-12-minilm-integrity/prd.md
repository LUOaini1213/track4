# MiniLM checkpoint identity

Implement the explicitly approved shared integrity validator for runtime and submission packaging. Preserve E123, rank(), evaluator semantics and historical measurement bytes. Do not download weights, run an encoder forward, call a paid service, push or publish in this task.

Acceptance: the official pinned revision authorizes the manifest; symbolic/local self-signed identity cannot bypass it. All six load files are checked before Transformers. Failed local identity has generic nodense diagnostics. Package input/copy/import/archive failure preserves any previous ZIP. The private branch receives only public fixes and the already-public complete module allowlist. Offline fake files demonstrate guard behavior, never scored checkpoint equivalence.
